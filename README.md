# 🌐 Language Translator

A web-based Language Translation Tool developed as part of my CodeAlpha internship.

## 📌 Project Overview

The Language Translator allows users to enter text, select a source language and target language, and translate the text using a translation API.

The project also includes additional features such as text-to-speech, voice input, translation history, language swapping, copy functionality, dark mode, and a character counter.

## ✨ Features

- 🌐 Multiple language support
- 🔄 Language translation
- 🔁 Swap source and target languages
- 📋 Copy translated text
- 🔊 Text-to-speech
- 🎤 Voice input
- 🕘 Translation history
- 🌙 Dark mode
- 📊 Character counter
- 🗑️ Clear text
- 📱 Responsive design
- ⚠️ Error handling

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- Translation API
- Web Speech API
- LocalStorage
